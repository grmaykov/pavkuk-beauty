# Pavluk Beauty

Сайт студии перманентного макияжа Алины Павлюк.

Домен: https://pavluk-beauty.ru

Статический сайт: HTML, CSS и JavaScript. Фото и 16 видео находятся в `assets/`. Сборка и отдельное хранилище не требуются.

GitHub Pages: ветка `main`, папка `/ (root)`. Файл `.nojekyll` отключает обработку Jekyll.

Материалы перенесены без перекодирования. Права на фото, видео, тексты и оформление сохраняются за их правообладателями.
